# Drive 사진을 격자(썸네일)로 보기 — 기술 검토

2026-09-27. 요구: "앱에서 Google Drive 를 사진으로 보고 싶다. 다 받아와야 해서 오래 걸리면 안 한다."

## 결론

**된다. 원본을 받지 않는다.** Drive 가 서버에서 만들어 둔 **썸네일**을 쓰면, 화면에 보이는 칸만큼 작은 그림(장당 수십 KB)을
받는다. 지금 목록을 읽는 요청에 필드 하나를 더할 뿐 요청 수는 늘지 않는다.

## 무엇을 받나

| 무엇 | 크기 | 언제 |
|---|---|---|
| 폴더 목록(메타데이터) | 한 번에 최대 **1,000개**(`pageSize` 최대값) | 지금과 같다 — `fields` 에 `thumbnailLink` 만 더한다 |
| 썸네일 | 한 장 **수십 KB**(`=s220` 기준) | 칸이 화면에 들어올 때만(Coil 지연 로딩) |
| 원본 | 2~3MB(사진) | **누른 것 하나만** — 지금의 앱 안 미리보기와 같다 |

대략: 한 화면 20~30칸이면 썸네일 합계 1MB 안팎. 원본으로 격자를 채우는 것의 100분의 1 수준이다.
5,000장 폴더도 메타데이터는 1,000개씩 5번이면 끝나고, 스크롤할 때 다음 쪽을 이어 읽으면 처음 뜨는 시간은 한 쪽 분량이다.

## Drive API 근거

- `thumbnailLink` — "A short-lived link to the file's thumbnail, if available. Typically lasts on the order of hours."
- `hasThumbnail`, `thumbnailVersion`(썸네일 캐시 무효화용)
- `imageMediaMetadata.time` — 촬영 시각(EXIF). `videoMediaMetadata` — 길이·크기(올린 직후엔 없을 수 있음)
- `files.list` 의 `pageSize` 최대 1,000. `orderBy` 는 `createdTime`·`modifiedTime`·`name` 등 — **촬영 시각으로는 서버 정렬이 안 된다**

## 걸릴 만한 것

1. **링크가 몇 시간 뒤 만료된다.** 캐시 키를 링크가 아니라 `파일 ID + thumbnailVersion` 으로 잡는다. 그래야 다시 열 때
   링크가 바뀌어도 기기 캐시를 그대로 쓴다. 만료된 링크는 목록을 다시 읽으면 새로 온다.
2. **인증.** 썸네일 호스트(`googleusercontent.com`)가 우리 토큰을 요구하는지는 문서에 없다. 기기에서 확인한다.
   요구하면 지금의 Drive 이미지 로더(인증 붙음)로 받되, **토큰은 Google 호스트에만** 붙게 제한한다.
3. **막 올린 파일은 썸네일이 늦게 생긴다.** 그동안은 지금처럼 아이콘을 보인다.
4. **촬영일순 정렬은 서버가 못 한다.** 기본은 `modifiedTime desc`(또는 이름순 — 카메라 사진은 이름이 촬영 시각이라 거의 같다).
   촬영일로 묶어 보려면 그 폴더의 메타데이터를 끝까지 읽어야 한다(5,000장이면 요청 5번, 몇 초). 필요할 때만 켠다.
5. **권한.** 주 계정의 폴더는 `drive.file` 이라 앱이 올린 것만 보인다(지금과 같다). 보기 전용 폴더는 읽기 권한이라 전부 보인다.

## 만들 것

- 목록 요청 `fields` 에 `thumbnailLink, hasThumbnail, thumbnailVersion` 추가 → `DriveEntry` 에 싣는다
- Drive 화면에 **목록 ↔ 격자** 전환(`LazyVerticalGrid`). 폴더는 위에 목록처럼, 사진·영상은 격자로
- 격자 칸: 썸네일(Coil, 캐시 키 = ID+버전), 영상이면 재생 표시
- 격자일 때 `pageSize` 를 키운다(100 → 300 정도) — 칸이 작아 한 쪽이 금방 끝난다
- 누르면 지금의 앱 안 미리보기. 선택: 큰 썸네일(`=s1600`, 수백 KB)을 먼저 보이고 원본으로 바꾼다
- `DriveBrowserScreen.kt` 가 이미 600줄이라 격자는 새 파일로 뺀다

## 판단

**만들 만하다.** 요구의 조건("다 받아와서 오래 걸리면 안 한다")을 썸네일이 정확히 비켜 간다.
확인이 필요한 것은 하나 — 썸네일 링크에 토큰이 필요한지(§걸릴 만한 것 2). 기기에서 한 번 보면 끝난다.
