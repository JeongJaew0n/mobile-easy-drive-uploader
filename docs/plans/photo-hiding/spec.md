# 사진 숨기기

## 무엇을

보기 싫거나 남에게 보이고 싶지 않은 사진을 갤러리 목록에서 빼고, **비밀번호를 넣어야** 볼 수 있게 한다.

- 갤러리 선택 모드와 상세보기에서 **숨기기**
- 갤러리 ⋮ → **숨긴 사진 보기** → 비밀번호 → 전용 화면
- 그 화면에서 **숨김 해제**

## 어떻게 숨기나 — 파일을 옮기지 않는다

| 방식 | 판단 |
|---|---|
| 파일을 `.nomedia` 폴더로 옮긴다 | **안 쓴다** |
| 우리 Room 표에 id 를 적고 목록에서 뺀다 | **쓴다** |

파일을 옮기면 MediaStore 에서 사라져 다른 갤러리 앱에서도 안 보인다 — 숨김으로서는 더 강하다.
그런데 대가가 크다.

- 장마다 쓰기 동의(`createWriteRequest`)가 필요하다. 100장을 숨기려면 동의 창을 봐야 한다.
- 경로가 바뀌어 업로드 원장(`uploaded_media`)·중복 해시 캐시·자동 태그 기록이 전부 어긋난다.
- 숨김 해제 때 원래 폴더로 되돌리는 것을 우리가 보장해야 한다. 중간에 실패하면 사진이 미아가 된다.
- 사용자가 앱을 지우면 사진이 숨겨진 채 남는다.

**그래서 우리 앱 안에서만 숨긴다.** 대신 이 한계를 화면에 적는다 —
"다른 갤러리 앱에서는 보입니다".
거짓으로 안심시키는 것이 제일 나쁘다.

## 비밀번호

- **4~6자리 숫자 PIN.** 처음 "숨긴 사진 보기" 에 들어갈 때 설정한다.
- 저장은 **PBKDF2WithHmacSHA256**(반복 20만, 16바이트 난수 소금). 원문은 어디에도 두지 않는다.
- 비교는 `MessageDigest.isEqual` (길이 무관 상수 시간).
- **틀리면 잠근다.** 5회 틀리면 30초, 그 뒤로는 실패마다 2배(최대 10분). 4자리는 만 가지뿐이라
  제한이 없으면 잠금이 아니라 장식이다. 잠금 시각은 저장해 앱을 다시 켜도 유지한다.
- 잊었을 때: **되돌릴 방법을 두지 않는다.** 대신 설정에서 PIN 을 바꾸려면 현재 PIN 을 요구하고,
  "잊으면 숨긴 사진을 볼 수 없다" 를 설정 화면에 적는다.

이건 **엿보기 방지**지 암호화가 아니다. 파일 자체는 그대로고 기기를 뒤지면 나온다. 문서에 명시한다.

## 화면

```
갤러리 ⋮ → 숨긴 사진 보기
   │
   ├─ PIN 미설정 → [PIN 설정] 새 PIN + 확인 입력
   └─ PIN 설정됨 → [PIN 입력] ──맞으면──> 숨긴 사진 그리드
                      └─ 5회 실패 → 잠금(남은 시간 표시)
```

숨긴 사진 화면은 휴지통(`TrashScreen`)과 같은 골격 — 날짜별 그리드, 선택 모드, 하단 액션(숨김 해제).

## 어디서 빼나

| 화면 | 숨긴 사진 |
|---|---|
| 갤러리 목록(전체·카메라·스크린샷·다른 앱) | **뺀다** |
| 상세보기 스와이프 범위 | **뺀다** |
| 기간 선택 달력의 날짜별 개수 | **뺀다** (목록과 어긋나면 안 된다) |
| 휴지통 | 그대로 — 휴지통은 이미 별도 화면이다 |
| 중복 검사·자동 태그·자동 백업 | **그대로 둔다** |

마지막 줄이 중요하다. 숨김은 **보기**의 문제지 백업·분석을 멈추라는 뜻이 아니다.
숨긴 사진도 계속 백업된다 — 이걸 바꾸려면 사용자가 따로 말해야 한다. 문서에 적는다.
