# 백업된 사진 — 이 기기의 무엇이 어디에 올라갔나

2026-10-06. 기획: 백업 칸 기획 아티팩트 1부(https://claude.ai/artifact/3CgS8DbGbH9x8ZLZu3HWbz). 사용자가 제안대로 확정했다.
2부(Drive 사진, `docs/plans/drive-photos/spec.md`)를 먼저 만들었다.

## 1. 확정된 결정

| 물음 | 결정 |
|---|---|
| 백업됨을 무엇으로 묶나 | **올린 날짜** ("10월 5일 올림"). 안 됨은 찍은 날짜, 대기·실패는 까닭 |
| NAS 도 세나 | 센다. 저장소 칩으로 한 곳만 볼 수 있다 |
| 안 됨·대기·실패도 이 화면에 | 둔다 |

## 2. 화면

### 2.1 백업 칸 위쪽 — 요약 카드 + 최근 백업 띠
- "이 기기의 사진 N장 중 M장 백업됨 · P%". M 은 **어디든** 한 곳에라도 올라간 것(숨긴 사진 제외).
- 저장소별 막대와 범례(Google Drive 4,402 · MyNAS 510 · 실패 31). 한 사진이 두 곳에 올라갔으면 두 곳 모두에 센다 —
  막대는 저장소별 비율(저장소 수 / 기기 사진 수)이라 합이 100% 를 넘을 수 있어 **겹쳐 그리지 않고 줄마다** 그린다.
- 범례 아래 한 줄: 썸네일 ✓ 와 "올린 사진 기기에서 삭제" 는 **지금 업로드 대상 한 곳** 기준이라는 안내.
- 최근 백업 띠: 마지막으로 올린 기기 사진 8장. 카드·띠·"모두 보기" → 백업된 사진 화면.
- 사진 권한이 없으면 카드를 두지 않는다(셀 수 없다).

### 2.2 백업된 사진 화면(`BackedUpKey` → 갤러리 화면, `GalleryScope.Backup`)
- 갤러리 화면을 그대로 쓴다 — 선택·업로드·고른 사진·휴지통·더보기가 덤으로 된다. 출처 탭은 없다.
- 위: 세그먼트 **백업됨 / 안 됨 / 대기·실패**, 저장소 칩(모든 저장소 / 저장소마다). 대기·실패에는 칩이 없다(큐는 지금 대상 하나로 돈다).
- 백업됨: 올린 날짜(가장 최근에 올린 시각)로 묶고, 그 순서로. 머리글 "2026년 10월 5일 올림".
- 안 됨: 고른 저장소(또는 어디에도) 안 올라간 것, 찍은 날짜순. 사진 칸 ⋮ "백업 안 된 항목만 보기" 와 같은 목록이다(⋮ 는 남긴다).
- 대기·실패: 큐의 대기·진행 중 한 묶음 + 실패를 까닭(저장 공간·권한·로그인 …)별 묶음. 원장에 이미 있는 실패 줄은 뺀다.
- ⋮ 의 "백업 안 된 항목만 보기" 는 이 화면에 없다(세그먼트가 대신한다).

### 2.3 상세보기 정보 — "백업" 줄
- 그 사진의 원장 줄마다: 저장소 이름 · 올린 시각. Google Drive 는 "Drive 에서 열기"(연결 계정으로 연다).
- 원장에 없으면 줄이 없다.

## 3. 데이터

- 원장 전체 조회 `UploadedMediaDao.observeAll()` → `UploadLedgerRepository.observeRecords(): Flow<List<UploadRecord>>`.
- 저장소 이름: `drive:<email>` → "Google Drive"(연결 계정) 또는 "Google Drive · <email>"(다른 계정 업로드),
  `remote:<id>` → 연결된 저장소의 이름(지웠으면 id). 주인 미정 옛 기록은 "Google Drive".
- 대기·실패: 큐(`upload_tasks`) 의 `state`·`errorReason`. 실패 문장은 업로드 목록 화면과 같은 표(`uploadFailureRes`)를 쓴다.
- DB 스키마 변경 없음.

## 4. 코드 배치

- `core/domain/model/UploadRecord.kt` — 원장 한 줄, `BackupDestination`(목적지 + 이름)
- `core/data/upload/BackupDestinations.kt` — 목적지 → 이름(순수 함수, 테스트)
- `feature/gallery/BackupScope.kt` — 세그먼트·칩 상태, 거르기·묶기(순수 함수, 테스트), 위쪽 막대 UI
- `feature/backup/BackupSummaryCard.kt` — 요약 카드·최근 백업 띠
- 상세보기 정보 패널에 백업 줄
- 새 feature 를 만들지 않는다 — 갤러리 범위 하나 + 백업 칸 조각
