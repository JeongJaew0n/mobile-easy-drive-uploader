# Drive 사진 격자 보기 — 진행 계획

검토: `docs/DRIVE_PHOTO_GRID.md`. 2026-09-27 시작. 기기 확인은 S23+.

## 만드는 것

1. 목록 요청에 `thumbnailLink, hasThumbnail, thumbnailVersion` → `DriveEntry.thumbnailLink/thumbnailVersion`
2. 한 쪽 크기 100 → 300 (격자는 칸이 작아 한 쪽이 금방 끝난다. 목록에도 해롭지 않다 — 요청 수가 준다)
3. Drive 화면 상단에 **목록 ↔ 격자** 전환. 고른 모양은 설정에 남긴다(다시 열어도 그대로)
4. 격자(`DriveGrid.kt`, 새 파일): 폴더는 위에 한 줄씩(전체 폭), 사진·영상은 3열 정사각 칸
   - 썸네일은 인증 붙은 Drive 이미지 로더로. **캐시 키 = `파일 ID + thumbnailVersion`** — 링크는 몇 시간 뒤 바뀐다
   - 칸 크기에 맞게 `=s220` 을 `=s400` 으로 바꿔 받는다
   - 영상은 재생 표시, 썸네일이 없으면(막 올린 파일) 지금의 아이콘
   - 누르면 앱 안 미리보기, 길게 누르면 선택(목록과 같다)
5. 토큰은 **Google 호스트에만** 붙인다(`AuthInterceptor`). 썸네일 호스트가 `googleusercontent.com` 이라 로더가 그쪽도
   부르게 되는데, 혹시라도 다른 호스트로 새지 않게 막는다

## 확인할 것 (S23+)

- 썸네일 링크가 토큰을 요구하는지 — 받아지면 끝
- 보기 전용 폴더(거제, 강의 PDF 는 PDF 라 썸네일이 문서 모양)·주 계정 폴더 둘 다
- 스크롤할 때 다음 쪽이 이어지는지, 다시 열 때 썸네일을 다시 받지 않는지(캐시)

## 결과 (2026-09-27, S23+)

- 썸네일은 토큰 없이도 막히지 않고 받아졌다(모두 200, 장당 약 27KB). 격자·선택·미리보기·설정 유지 확인
- 남은 것: 300개 넘는 폴더의 페이징, 다시 열 때 캐시, 주 계정·PDF 폴더 — `docs/manual-tests/02-google-drive.md` GRD-06~08
