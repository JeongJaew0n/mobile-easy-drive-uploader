# UX 2차 — 선택 하단바·빈 화면 버튼·휴지통 실행 취소·격자 확대

2026-10-05. 사용자: "작업 시작해." `docs/UX_RESEARCH.md` §4 의 1·2·4·6번. 선택 하단바의 넷은 따로 정하지 않아
제안대로 **업로드·고른 사진·휴지통·더보기**로 간다. 기기 테스트는 지시가 있을 때.

## 1. 선택 하단바 — 글자 붙은 넷 + 더보기 시트

| 자리 | 지금 | 바뀐 뒤 |
|---|---|---|
| 상단바 | ✕ · N개 선택 · 업로드 · ⋮(다른 저장소·다른 계정) | ✕ · N개 선택 |
| 하단바 | 아이콘만 9개 | **업로드 · 고른 사진(넣기/빼기) · 휴지통 · 더보기** — 아이콘 아래 글자 |
| 더보기 시트 | — | 즐겨찾기 · 숨기기 · 카테고리 · 이름 변경(하나일 때) · 앨범으로 이동 · 다른 저장소로 업로드 · 다른 계정으로 업로드 · **완전 삭제**(맨 아래, 빨강) |

근거: 글자 없는 앱 고유 아이콘은 뜻을 맞히는 비율이 34%(NN/g). Android 10(API 29)은 휴지통·즐겨찾기가 없어
휴지통 자리가 "삭제" 가 된다.

## 2. 빈 "고른 사진" 에 버튼

안내 문구 아래 **"전체에서 고르기"** — 누르면 전체 탭. 튜토리얼 대신 빈 화면에서 바로 갈 곳을 준다(NN/g).

## 4. 휴지통 — 실행 취소, 또는 권한 제안

- 미디어 관리 권한이 **있으면**: 휴지통으로 옮긴 뒤 스낵바에 **"실행 취소"**. 누르면 그대로 되돌린다(확인 창 없음).
- **없으면**: 실행 취소도 시스템 확인 창을 한 번 더 띄우므로 두지 않는다. 대신 첫 휴지통 이동이 끝난 뒤 **한 번만**
  "매번 묻지 않게 하려면 미디어 관리를 허용하세요 · 허용" 을 보인다(`manageMediaHintShown`).
- 갤러리·상세보기에 건다. 휴지통 화면(복원)·백업 칸(대량)에는 걸지 않는다.

## 6. 격자 확대·축소 + 날짜 스크롤

- **두 손가락 오므리기/벌리기**로 칸 크기 다섯 단계(최소 64·80·100·130·170dp). 한 손가락(스크롤·끌어서 고르기)은
  건드리지 않는다 — 두 번째 손가락이 닿았을 때만 듣는다. 칸 크기는 설정에 남는다(`galleryCellSizeStep`).
- 단계가 바뀌어도 **보던 첫 항목**이 그대로 위에 오도록 스크롤을 되잡는다(목록은 key 로 묶여 있어 index 가 같다).
- 모션 규칙: 칸 크기 애니메이션은 하지 않는다(크기 애니메이션 금지).
- **오른쪽 가장자리 날짜 손잡이**: 끌면 목록 전체를 그 비율로 건너뛰고, 끄는 동안 그 자리의 날짜(연·월)를 말풍선으로 보인다.
  목록이 짧으면(항목 60개 이하) 보이지 않는다. 갤러리에서만 — 숨긴 사진·휴지통 격자에는 없다.
