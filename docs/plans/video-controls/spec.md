# 영상 컨트롤 — 얇은 재생바 하나, 한 줄 컨트롤

2026-10-18. 사용자: "동영상 플레이어 재생바가 너무 구린데" → 제안(구글 포토·유튜브식)을 추천대로 확정.

## 지금 문제
1. 막대가 둘(음량·재생 위치)인데 음량이 더 굵어 어느 것이 재생바인지 헷갈린다
2. Material 3 기본 Slider 그대로 — 굵은 막대·세로 막대기 손잡이, 설정 화면 같은 모양
3. 아래에 회색 상자를 통째로 깔아 영상을 가린다
4. 기기 영상과 Drive 영상의 컨트롤이 따로 생겼다

## 바꾸는 것
- **공용 재생바 `VideoSeekBar`**(`core/ui/media`): 평소 3dp 흰 선 + 작은 동그라미 손잡이. 끄는 동안 손잡이가 커지고(그리기 단계 배율 —
  레이아웃 크기 애니메이션 아님) 위에 시간 말풍선. 손이 닿는 높이는 넉넉히(36dp). 누른 자리로 바로 이동. 끄는 동안은 페이저·스와이프 닫기가 끼어들지 않는다
- **음량 막대 없앰** — 🔊 는 음소거 켜고 끄기, 음량은 폰 버튼(구글 포토·삼성 갤러리 방식)
- **한 줄**: 재생바 아래에 ❚❚/▶ · "0:03 / 0:08" ……… 🔊 1x ⟲. 가운데 큰 재생 버튼은 그대로
- **회색 상자 대신 아래로 갈수록 어두워지는 그림자**
- **두 번 톡: 왼쪽 반 = 10초 뒤로, 오른쪽 반 = 10초 앞으로**, 그 쪽에 "−10초/+10초" 잠깐. 한 번 톡은 지금처럼 컨트롤 보이기/숨기기
  (두 번 톡을 기다리느라 한 번 톡이 조금 늦어진다 — 유튜브와 같다)
- **Drive 영상도 같은 재생바·그림자**(두 번 톡은 넣지 않는다 — Drive 넘겨 보기는 영상 쪽에서 톡을 쓰지 않는다)
