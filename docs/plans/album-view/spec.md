# 앨범별로 보기 — 계획

2026-09-28. 요구: "그룹이 아니라 앨범이다. 앨범 볼 수 있게 구현해." (기기 테스트는 하지 않는다)
배경: 카톡 사진 선택에 보이는 "삼성에서 만든 것" 은 앨범 = 실제 폴더(`docs/SAMSUNG_GALLERY_INTEROP.md` §4.2).

## feature

새 feature 를 만들지 않는다. 갤러리를 거르는 방법 하나라 `feature/gallery` 에 넣는다 — 카테고리 필터와 같은 자리.
용어는 이미 있는 **앨범 (Album)** 을 그대로 쓴다(용어집: MediaStore 의 `relativePath` 한 칸).

## 모양

⋮ → **앨범** → 앨범 격자 시트(대표 사진·이름·개수, 최근 사진이 있는 앨범부터) → 누르면 그 앨범만 보인다.
위에 앨범 막대(폴더 아이콘·이름·✕)가 붙고, 제목이 앨범 이름이 된다. ✕ 로 풀린다.

탭을 하나 더 두지 않는다. 다섯 칸으로 이미 라벨 여백을 줄였다(GAL-55).

카테고리 필터와 같은 방식이라 선택·업로드·삭제·이동·기간·즐겨찾기가 그대로 동작한다.

## 규칙

- 앨범을 고르면 **탭을 '전체' 로** 옮긴다. "고른 사진" 탭 안에서 앨범을 고르면 두 조건이 겹쳐 비어 보인다.
  탭을 바꾸면 앨범도 풀린다(다른 필터와 같다, 2026-09-17 결정).
- 거르는 순서: 숨김 → 탭 → **앨범** → 백업 → 카테고리 → 기간.
- 앨범 목록은 숨긴 사진을 뺀 전체에서 만든다(이동 대상과 같다). 숨긴 사진만 있는 앨범은 나오지 않는다.

## 같이 고치는 것 — 상세보기의 범위

상세보기는 즐겨찾기·기간·카테고리만 이어받는다. 그래서 **앨범에서 열어도 좌우로 넘기면 다른 앨범 사진이 나온다.**
탭도 이어받지 않아 "고른 사진"(2026-09-27)·카메라 탭에서 열어도 전체를 넘긴다 — 같은 원인이라 함께 고친다.
`MediaViewerKey` 에 `tab`·`albumPath` 를 더한다.

## 확인

- 단위 테스트: 앨범 필터, 앨범 고르면 탭이 전체로, 탭 바꾸면 앨범 해제, 상세보기가 탭·앨범 범위를 지킨다
- 기기(지시가 있을 때): `docs/manual-tests/01-gallery-basics.md` ALB-*

## 바뀜 (2026-10-05)

⋮ → 앨범 시트와 앨범 막대는 **하단 앨범 칸**으로 대체했다 — 앨범 하나는 범위(`GalleryScope`)를 건 갤러리 화면이다.
상세보기가 탭·앨범 범위를 잇는 부분은 그대로 쓴다. `docs/plans/bottom-navigation/spec.md`.
