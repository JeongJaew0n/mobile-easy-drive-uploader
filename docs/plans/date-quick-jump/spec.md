# 기간 선택 — 연·월 빠른 이동

작성 2026-09-16.

## 문제
기간 선택 시트(`DateRangeSheet`, `docs/DATE_RANGE_PICKER.md`)는 세로 스크롤 달력 하나뿐이다.
사진이 2021~2026년 6년치라, 예전 달을 고르려면 한참 스크롤해야 한다.

## 방식 (사용자 확정, 2026-09-16)
달력 위 **월 제목을 탭하면 연·월 점프 패널**이 펼쳐진다. 연도·월을 고르면 그 달로 스크롤한다.
날짜는 지금처럼 달력에서 고른다("사진 있는 날 점·범위 띠"를 유지).

## 상세
- **월 제목 위치**: 지금은 각 월 블록 안에 `MonthHeader` 로 있다. 스크롤을 따라 움직여 탭 대상이 불안정하다.
  → 달력 위에 **고정 헤더**를 하나 두고, 현재 보이는 달을 표시한다(`calendarState.firstVisibleMonth`).
  고정 헤더가 생기므로 월 블록 안의 `MonthHeader` 는 남겨 둔다(스크롤 중 어느 달인지 구분).
- **탭 → 점프 패널**: 고정 헤더를 누르면 그 아래(또는 달력 자리)에 패널이 열린다.
  - **연도 행**: 사진이 있는 연도만(`dayCounts` 의 연도 집합). 가로 배치, 선택 연도 강조.
  - **월 그리드**: 1~12. 그 연도에 **사진이 있는 달만** 활성, 없으면 흐리게. 미래 달도 흐리게.
  - 월을 누르면 패널을 닫고 `animateScrollToMonth(그 달)`.
- **범위 밖 방어**: 고른 달이 `startMonth`~`thisMonth` 를 벗어나면 `coerceIn`.
- **상태**: 패널 열림 여부는 시트 로컬 상태. 다시 누르면 닫힌다.

## 건드리지 않는 것
- 프리셋 칩(오늘·최근 7일·30일·올해), 날짜 선택·범위 로직, 적용/취소.
- MediaStore·정렬. 이 작업은 순수 UI다.

## 검증
- 단위: 연·월 점프 대상 계산(범위 밖 coerce, 사진 없는 달 비활성 판정)을 순수 함수로 빼서 테스트.
- 실기기: 월 제목 탭 → 2021년 → 사진 있는 달 선택 → 그 달로 스크롤, 날짜 선택까지.
