# Flip 4 에서 업로드가 느리다 — 대부분 화면 꺼짐과 영상 때문

2026-09-27. Flip 4 에서 "다른 계정 업로드"(B = popt0394, 폴더 `엄마꺼`, 5,700여 장 + 영상 100여 개)가 느리다는 말.

## 처음 판단은 틀렸다

처음에는 10초 동안 잰 **1.5Mbps** 를 근거로 "Flip 4 → Google 구간만 16배 느리다" 고 보고, 공유기의 기기별 제한이나
Google 쪽 제한을 의심했다. **한순간 표본이었다.** 전체를 재 보니 그렇게 느리지 않았다.

| 측정 | 값 |
|---|---|
| 완료된 양 ÷ 걸린 시간(DB 의 `updatedAt`) | **1,686MB / 15.9분 ≈ 14Mbps**(초당 1.8MB) |
| 화면 켜진 채 15초 송신 | **24.5Mbps** |
| (참고) S23+ 의 대량 업로드 최고치 | 약 34Mbps(1,051장 / 12.2분) |

**교훈: 속도는 한순간이 아니라 완료량 ÷ 시간으로 잰다.** 업로드는 세션 생성·영상 PUT·화면 꺼짐으로 출렁인다.

## 실제로 느려지는 이유

**1. 화면이 꺼지면 3~4배 느려진다.** 로그에서 한 장 시간을 분 단위로 보면

```
08:50~08:54  화면 켜짐   한 장 2.5~4.9초
08:55        화면 꺼짐
08:56~08:57             한 장 12~13초
```

Flip 4 는 배터리로 돌고 있어(`AC/USB powered: false`) 화면이 꺼지면 Wi-Fi 가 절전 모드로 들어간다.
화면 꺼짐 시간은 이 기기의 원래 값(10분)이다. 테스트하는 동안은 24시간으로 바꿔 두었다가 원래대로 돌렸는데,
그 사이에는 화면이 안 꺼져 빨랐으니 **"되돌린 뒤로 느려졌다"** 고 느낄 만하다.

**2. 남은 것의 절반이 영상이다.** 대기 중 사진 5,423장(4.7GB)·영상 72개(4.7GB). 영상은 한 개 평균 60MB 대라
한 개가 사진 수십 장만큼 걸린다.

## 배제한 것 (그대로 유효)

앱 코드(요청 사이에 기다리는 시간 없음, 토큰·401·한도·재시도 로그 없음), 모바일 데이터로 새기(지금 `wlan0` 로만 나간다),
VPN·Private DNS, IPv6, TCP 버퍼, 포그라운드 서비스 시간 초과.

## 빠르게 하려면

- 올리는 동안 **충전기를 꽂고 화면을 켜 둔다.** Flip 4 는 "충전 중 화면 켜둠" 이 꺼져 있다(`stay_on_while_plugged_in=0`).
- 앱에서 할 수 있는 것: 업로드 중에는 화면을 켜 두는 선택지(`FLAG_KEEP_SCREEN_ON`)를 두는 것 — 필요하면 따로 정한다.
