# Flip 4 에서 업로드가 느리다 — 조사 중

2026-09-27. Flip 4 에서 "다른 계정 업로드"(B = popt0394, 폴더 `엄마꺼`, 5,720장)를 돌리는데 느리다.
**원인은 아직 확정하지 못했다.** 잰 것과 배제한 것을 남긴다.

## 증상

2.6MB JPEG 한 장이 **17~43초** 걸린다(4장 동시). S23+ 에서는 같은 크기가 2~3초였다.

## 잰 것

| 측정 | 결과 | 뜻 |
|---|---|---|
| 요청 하나의 시간(OkHttp 로그) | `--> POST multipart` 08:41:05 → `<-- 200` 08:41:26 (**21초**) | 앱 안에서 기다리는 게 아니라 **보내는 동안**이 느리다 |
| 메타데이터만 보내는 요청(세션 생성) | 2.9초 | 큰 업로드와 같은 연결(HTTP/2)을 써서 뒤에서 기다린다 |
| 지금 인터페이스별 송신(10초) | `wlan0` 1.82MB = **1.5Mbps**, 셀룰러 0 | Wi-Fi 로 나가고 있다. LTE 로 새는 것 아님 |
| 폰 → 맥(같은 공유기) 60MB | Flip 4 **42.6Mbps**, S23+ 69.5Mbps | 폰의 Wi-Fi 업로드는 멀쩡하다 |
| 맥 → 인터넷(Cloudflare) 10MB | **202Mbps** | 집 회선도 멀쩡하다 |
| Google 까지 ping | Flip 4 64ms, S23+ 73ms | 쉬고 있을 때 지연은 같다 |
| Wi-Fi 신호 | Flip 4 −57dBm / 172Mbps | 약하지 않다 |

## 배제한 것

- **앱 코드** — 같은 경로(`GuestDriveFactory` 는 기존 Drive 코드에 토큰만 바꿔 끼운다)가 S23+ 에서 빠르다.
  시간이 요청 하나 안(보내는 중)에서 샌다. 토큰 재발급·401·한도(403/429)·재시도 로그 없음.
- **모바일 데이터로 새기** — 지금 `wlan0` 로만 나간다. (`netstats` 의 셀룰러 32.6MB 는 Wi-Fi 에 붙기 전 누적치였다.)
- **VPN·Private DNS** — 두 폰 다 없다.
- **IPv6 경로** — 두 폰 다 전역 IPv6 가 없고 IPv4 로 붙는다.
- **TCP 버퍼** — 두 폰 `tcp_wmem` 이 같다(2~8MB).
- **포그라운드 서비스 시간 초과** — 로그의 `Stop FGS timeout` 은 08:42:45 인데 느린 건 08:41 에도 그랬다.

## 남은 가설

**Flip 4 → Google 구간만** 느리다(폰 Wi-Fi·회선은 빠르다).

1. 공유기의 기기별 속도 제한·QoS — 폰→맥은 공유기 안에서 끝나 WAN 을 안 지난다. 기기별 제한이면 이 측정에 안 잡힌다.
2. Google 쪽 계정·앱 단위 제한 — 오늘 이 계정으로 수천 장을 올렸다.

**다음에 할 것:** S23+ 에서 같은 계정으로 같은 크기 사진을 지금 올려 시간을 비교한다.
S23+ 도 느리면 2(Google 쪽), 빠르면 1(Flip 4 쪽 경로)이다.
