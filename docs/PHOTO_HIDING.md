# 사진 숨기기

갤러리 목록에서 사진을 빼고, 비밀번호를 넣어야 볼 수 있게 한다.
진행 계획은 `docs/plans/photo-hiding/`.

## 1. 무엇을 하지 않는가 — 파일을 옮기지 않는다

`hidden_media(mediaId, hiddenAt)` 표에 id 를 적고 **우리 목록에서만** 뺀다.
파일도, MediaStore 행도 그대로다.

`.nomedia` 폴더로 옮기는 방식을 쓰지 않은 이유:

- 장마다 쓰기 동의(`createWriteRequest`)가 필요하다. 100장을 숨기려면 동의 창을 100번 본다.
- 경로가 바뀌어 업로드 원장·중복 해시 캐시·자동 태그 기록이 전부 어긋난다.
- 되돌릴 때 원래 폴더 복구를 우리가 보장해야 한다. 중간에 실패하면 사진이 미아가 된다.
- 앱을 지우면 사진이 숨겨진 채 남는다.

**그래서 다른 갤러리 앱에서는 그대로 보인다.** 이 한계를 화면에 적는다
(`hidden_note`: "이 앱에서만 숨겨집니다. 다른 갤러리 앱에서는 보입니다.").
거짓으로 안심시키는 것이 제일 나쁘다.

## 2. 비밀번호

4~6자리 숫자 PIN. 처음 "숨긴 사진 보기" 에 들어갈 때 설정한다.

| 항목 | 값 |
|---|---|
| 해시 | PBKDF2WithHmacSHA256, 20만 회, 256비트 |
| 소금 | 16바이트 난수(`SecureRandom`), PIN 마다 새로 |
| 비교 | `MessageDigest.isEqual` (상수 시간) |
| 저장 | 별도 DataStore `hidden_pin` — 환경설정과 섞지 않는다 |

**원문은 어디에도 두지 않는다.**

### 잠금

4자리는 만 가지뿐이라 제한이 없으면 잠금이 아니라 장식이다.

```
실패 1~5회  → 그냥 다시
     6회    → 30초
     7회    → 60초 … 실패마다 두 배
     11회~  → 600초(상한)
```

잠금 시각은 저장하므로 앱을 다시 켜도 유지된다. 잠긴 동안에는 **검사 자체를 하지 않고**
실패로 세지도 않는다 — 기다리는 사이에 잠금이 계속 늘어나면 안 된다.

**기기 시계를 되돌리면 잠금이 풀린다.** 로컬 앱이라 막을 방법이 없다(서버가 필요하다). 감수한다.

### 잊었을 때

되돌릴 방법을 두지 않았다. 뒷문을 만들면 잠금이 아니다.

## 3. 화면

```
갤러리 ⋮ → 숨긴 사진 보기
   ├─ PIN 미설정 → 설정(새 PIN + 확인)
   └─ PIN 설정됨 → 입력 ──맞으면──> 숨긴 사진 그리드(휴지통과 같은 골격)
                      └─ 잠김 → 남은 초를 세어 보여준다
```

- **화면을 벗어나면 다시 잠근다**(`DisposableEffect { onDispose { lock() } }`).
  뒤로 갔다 오면 또 물어야 숨김이다.
- PIN 을 통과하기 전에는 **목록을 만들지도 않는다** — 잠긴 상태의 UiState 에 사진이 없다.
- 남은 시간은 화면에서 직접 센다. 저장소를 1초마다 깨우지 않는다.

## 4. 어디서 빼나

| 대상 | 숨긴 사진 |
|---|---|
| 갤러리 목록(모든 탭) | **뺀다** — 메모리 필터 중 **가장 바깥**이다 |
| 기간 선택 달력의 날짜별 개수 | **뺀다** — 점이 있는데 목록이 비면 버그로 보인다 |
| 상세보기 스와이프 범위 | **뺀다** — 갤러리에 없는데 스와이프로 나오면 숨김이 아니다 |
| 앨범(이동 대상) 목록 | **뺀다** — 숨긴 사진만 있는 폴더가 뜨면 있다는 사실이 새어 나간다 |
| 중복 사진 화면 | **뺀다** — 이 화면은 **썸네일을 보여준다**. 넣으면 숨김이 그대로 새어 나간다 |
| 자동 백업의 폴더 목록 | **뺀다** — 앨범 목록과 같은 이유 |
| 휴지통 | 그대로 |
| 자동 태그·자동 백업의 **동작** | **그대로 둔다** |

마지막 줄은 의도된 것이다. 숨김은 **보기**의 문제지 백업·분석을 멈추라는 뜻이 아니다.
**숨긴 사진도 계속 백업되고 계속 라벨이 붙는다.** 자동 태그 화면은 라벨과 개수만 보여주고
썸네일이 없어서 그대로 두었다 — 다만 라벨 개수에는 숨긴 사진도 포함된다.

> 처음에는 "중복 검사도 그대로 둔다" 로 적었는데 틀렸다. 그 화면은 썸네일을 그린다.
> 화면이 무엇을 그리는지 보지 않고 "분석 기능이니까 상관없다" 로 묶은 판단 착오였다.

## 5. 하지 않은 것

- **화면 캡처 차단(`FLAG_SECURE`)** — 숨긴 사진 화면에만 걸면 일관성이 없고,
  이 기능은 암호화가 아니라 엿보기 방지다. 할 수 있는 것보다 크게 약속하지 않는다.
- **생체 인증** — PIN 하나로 충분하다.
- **숨긴 사진 자동 백업 제외** — 위 표 참고. 필요해지면 그때 설정으로 뺀다.
