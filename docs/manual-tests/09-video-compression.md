# 09 · 업로드 영상 압축 (Media3 Transformer)

설정 → 업로드 → "업로드 영상 압축". 기기 원본은 변하지 않고 Drive 사본만 변환된다.

| ID | 시나리오 | 기대 결과 | 상태 | 메모 |
|---|---|---|---|---|
| VC-01 | 프리셋 선택 다이얼로그 | 원본 / 1080p / 720p 라디오, 설명 문구 | ⬜ | |
| VC-02 | 720p 선택 후 4K 영상 업로드 | 알림 "영상 압축 중 (n/m)" 진행률 → 이어서 업로드. Drive 파일이 .mp4, 원본보다 작음, 재생 정상 | ⬜ | 짧은 변 720, H.264 4 Mbps |
| VC-03 | 세로 4K 영상 | 720×1280 로 나옴(짧은 변 기준), 회전 유지 | ⬜ | `Presentation.createForShortSide` |
| VC-04 | 이미 720p 이하 영상 | 압축 없이 원본 그대로 업로드 | ⬜ | |
| VC-05 | 사진 | 영향 없음 | ⬜ | |

| VC-07 | 업로드 완료 후 | 캐시 파일 삭제됨(`adb shell run-as` 불가 → 설정의 앱 저장공간 "캐시" 크기로 확인) | ⬜ | |

| VC-10 | 10분 4K 영상 압축 시간·발열 | 기기 인코더 성능에 따름 — 체감 기록 | ⬜ | Wi-Fi·충전 제약은 업로드 워커 전체에 적용되므로 압축도 그 조건에서만 |
