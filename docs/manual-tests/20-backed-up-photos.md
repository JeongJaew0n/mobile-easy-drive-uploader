# 20. 백업된 사진 — 백업 칸 요약·백업 범위 갤러리·상세 정보의 백업 줄

설계: `docs/plans/backed-up-photos/spec.md`. 목적지 이름·묶기·순서(백업됨·안 됨·대기·실패)·요약 숫자는 단위 테스트가 덮는다.

| ID | 시나리오 | 기대 결과 | 상태 | 메모 |
|---|---|---|---|---|
| BUP-01 | 백업 칸 맨 위 | "이 기기의 사진 N장 중 · M장 백업됨 · P%", 저장소마다 막대 한 줄, 실패가 있으면 "실패 N개" | ⬜ | 숨긴 사진은 세지 않는다 |
| BUP-02 | 저장소 둘 이상(Drive + NAS) | 막대가 둘. 아래에 "썸네일 ✓ 와 … 한 곳만 셉니다" 안내 | ⬜ | 두 곳에 다 올린 사진은 두 막대 모두에 든다 |
| BUP-03 | 최근 백업 띠 | 마지막으로 올린 8장. 카드·띠·"모두 보기" 어디를 눌러도 백업된 사진 화면 | ⬜ | |
| BUP-04 | 백업된 사진 — 백업됨 | "2026년 10월 5일 올림" 머리글, 가장 최근에 올린 것부터. 출처 탭 없음, ← 와 제목 | ⬜ | |
| BUP-05 | 저장소 칩 | 고른 곳에 올라간 것만. 다른 계정 업로드는 "Google Drive · b@…" 칩 | ⬜ | 저장소가 하나뿐이면 칩 줄이 없다 |
| BUP-06 | 안 됨 | 찍은 날짜순. 칩으로 "NAS 에 없는 것" 도 본다. 길게 눌러 고르고 업로드 → 대기·실패로 옮겨 간다 | ⬜ | |
| BUP-07 | 대기·실패 | "대기·올리는 중" 묶음 + 실패 까닭별 묶음(개수 표시). 칩 없음 | ⬜ | 저장 공간 가득·권한·로그인 문장이 업로드 목록과 같다 |
| BUP-08 | 묶음 머리글의 동그라미 | 그 묶음 전체 선택. 까닭 묶음은 "이 묶음 전체 선택" 으로 읽는다(TalkBack) | ⬜ | |
| BUP-09 | 백업됨에서 사진을 열어 좌우로 | 격자와 같은 순서(올린 날짜순)로 넘어간다 | ⬜ | 백업 범위 밖 사진이 끼지 않는다 |
| BUP-10 | 상세보기 ⓘ | "백업" 줄: 저장소 · 올린 시각. Google Drive 줄에 "Drive 에서 열기" → Drive 앱(연결 계정)에서 그 파일 | ⬜ | 다른 계정 업로드는 그 계정으로 열린다 |
| BUP-11 | 원장에 없는 사진의 ⓘ | 백업 줄이 없다 | ⬜ | |
| BUP-12 | ⋮ 메뉴 | 백업된 사진 화면에는 "백업 안 된 항목만 보기" 가 없다. 사진 칸에는 그대로 있다 | ⬜ | |
| BUP-13 | 사진 권한 없이 백업 칸 | 요약 카드가 없고 나머지는 그대로 | ⬜ | |
| BUP-14 | 영어·일본어 | 세그먼트 세 칸이 한 줄(Backed up·Not yet·Queued / 完了·未完了·待機・失敗) | ⬜ | |
