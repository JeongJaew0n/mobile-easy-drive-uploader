# 19. Drive 사진 — 폴더를 가로지른 사진첩·넘겨 보기

설계: `docs/plans/drive-photos/spec.md`. 조회 조건·EXIF 시각·달별 묶기·기기에 있음 판정·찍은 날짜순 정렬·휴지통 되돌리기는 단위 테스트가 덮는다.

| ID | 시나리오 | 기대 결과 | 상태 | 메모 |
|---|---|---|---|---|
| DPH-01 | Google 계정 연결 상태로 백업 칸 | 업로드 상태 아래 "Google Drive 사진" 카드, 최근 사진 썸네일 띠(최대 8장). "Google Drive 파일 보기" 줄은 없다 | ⬜ | |
| DPH-02 | 띠의 썸네일 하나 누르기 | Drive 사진 화면이 열리며 그 사진의 넘겨 보기가 바로 뜬다 | ⬜ | |
| DPH-03 | 카드/"모두 보기" | Drive 사진 화면 — 여러 폴더의 사진이 올린 날짜 최신순 격자, 달 머리글 | ⬜ | 기본 폴더·지정 폴더에 나뉘어 올린 것이 한 화면에 |
| DPH-04 | 기기에서 지운 사진·다른 기기에서 올린 사진 | 칸 오른쪽 위 ☁. "기기에 없음" 을 누르면 그것만 | ⬜ | 걸러서 적으면 알아서 더 읽는다 |
| DPH-05 | "영상" | 영상만, 칸에 길이 | ⬜ | 막 올린 영상은 길이 없이 ▶ 만 |
| DPH-06 | 범위 칩(폴더 하나) | 그 폴더 바로 아래 사진만. 보기 전용 폴더는 "(보기 전용)" 이 붙고 휴지통 단추가 없다 | ⬜ | |
| DPH-07 | 읽기 권한(보기 전용 폴더용)을 준 계정 | "앱으로 올린 것" 에 남의 공유 사진이 섞이지 않는다. "Drive 전체 (보기 전용)" 칩이 있다 | ⬜ | |
| DPH-08 | ⋮ → 찍은 날짜순 | "모두 읽는 중… N개" 뒤 찍은 날짜 순으로, 영상·EXIF 없는 것은 올린 날짜 자리 | ⬜ | 수천 장이면 몇 초 |
| DPH-09 | 넘겨 보기에서 좌우로 | 옆 사진이 큰 썸네일로 먼저 보이고 원본으로 바뀐다. 영상은 멈춘 쪽만 재생 | ⬜ | 넘기는 사이 소리가 겹치지 않는다 |
| DPH-10 | 넘겨 보기 위 막대 | 이름, 찍은 시각·크기·"이 기기에는 없음/이 기기에도 있음". 받기·휴지통·Drive 앱에서 열기 | ⬜ | 화면을 누르면 막대가 숨는다/나온다 |
| DPH-11 | 넘겨 보기에서 받기 | 다운로드 시작 스낵바, 알림에 진행. 끝나면 그 칸의 ☁ 가 남는다 | ⬜ | 받은 사진은 원장과 이어지지 않아 ☁ 가 남는다 — 의도와 맞는지 확인 |
| DPH-12 | 넘겨 보기·선택에서 Drive 휴지통 | 목록에서 빠지고 "실행 취소" → 제자리로 | ⬜ | 마지막 한 장이면 넘겨 보기가 닫힌다 |
| DPH-13 | 길게 눌러 여러 장 고르기 | 상단에 N개 선택 · 전체 선택 · 받기 · 휴지통 | ⬜ | 뒤로 가기는 선택 해제 |
| DPH-14 | 상단 폴더 단추 | 지금의 Drive 폴더 화면 | ⬜ | |
| DPH-15 | 폴더 화면 처음 열기(설정을 바꾼 적 없음) | 격자로 보인다 | ⬜ | 목록으로 바꾼 사람은 그대로 목록 |
| DPH-16 | 폴더 화면에서 사진 누르기 | 같은 넘겨 보기 — 그 폴더의 사진·영상끼리 | ⬜ | |
| DPH-17 | 비행기 모드로 백업 칸 | 카드는 남고 띠만 비어 있다. 들어가면 오류 + 다시 시도 | ⬜ | |
| DPH-18 | Google 계정 없이 백업 칸 | Drive 카드가 없다 | ⬜ | |
| DPH-19 | 영어·일본어 | 거르기 버튼 세 개가 한 줄에 들어간다 | ⬜ | "Not on phone" / "端末にない" |
