# 07 · 자동 백업

전제: Google 계정 연결(02 DRV-02) 완료. 설정 → 자동 백업.

| ID | 시나리오 | 기대 결과 | 상태 | 메모 |
|---|---|---|---|---|
| AB-01 | 로그인 전 화면 진입 | 스위치 비활성 + "먼저 Google 계정을 연결하세요" | ⬜ | |
| AB-02 | 앨범 목록 | 기기의 앨범(RELATIVE_PATH 단위)이 이름·경로·개수와 함께 나열, 체크 토글 | ⬜ | |
| AB-03 | 스위치 ON | 기준 시점이 "지금"으로 잡혀 기존 사진이 큐에 들어가지 **않음**. WorkManager 에 트리거·주기 워크 등록 | ⬜ | `adb shell dumpsys jobscheduler \| grep easygallery` 로 확인 가능 |
| AB-04 | ON 상태에서 카메라로 사진 1장 촬영 | 30초~5분 안에 업로드 대기열에 자동 추가 → 업로드 알림 | ⬜ | 콘텐츠 URI 트리거. 앱을 완전히 종료한 상태에서도 |
| AB-05 | 연속 촬영 5장 | 5번 깨지 않고 1~2번의 스캔으로 5장 모두 추가 | ⬜ | `setTriggerContentUpdateDelay(30s)` |
| AB-06 | 선택하지 않은 앨범(스크린샷 등)에 새 파일 | 추가되지 **않음** | ⬜ | |
| AB-07 | "영상 포함" OFF 후 영상 촬영 | 추가되지 않음 | ⬜ | |
| AB-08 | 이미 백업된 사진이 있는 앨범에서 "지금 검사" | "새로 백업할 항목이 없습니다" — 원장·큐 중복 방지 | ⬜ | |
| AB-09 | "기존 항목 모두 백업" | 확인 다이얼로그에 미백업 개수 → 확인 시 그만큼 큐 등록 | ⬜ | 수천 장이면 시간이 오래 걸림 — Wi-Fi 확인 |
| AB-10 | 스위치 OFF | 트리거·주기 워크 취소, 이후 촬영해도 추가 안 됨. 다시 ON 하면 기준 시점이 새로 잡힘 | ⬜ | |
| AB-11 | 앱 강제 종료 → 재시작 (ON 상태) | `ensureScheduled` 로 워크가 살아 있음 | ⬜ | |
| AB-12 | 기기 재부팅 후 촬영 | WorkManager 가 재부팅 후 워크를 복원해 자동 추가됨 | ⬜ | |
| AB-13 | 마지막 검사 시각 표시 | 스캔 후 "마지막 검사: n분 전" 갱신 | ⬜ | |
| AB-14 | 전력: ON 상태로 하루 방치 | 배터리 사용 내역에서 앱이 눈에 띄지 않음(트리거는 이벤트 기반, 주기 폴백 6시간) | ⬜ | `batterystats` |
| AB-15 | DB 마이그레이션 v1→v2 | 이전 버전(`df31aac` 이하) 설치 상태에서 업데이트 후 크래시 없음, 기존 큐 유지 | ⬜ | `AutoMigration(1→2)` — 테스트 기기에 v1 이 설치돼 있으므로 업데이트 설치로 바로 확인 가능 |
