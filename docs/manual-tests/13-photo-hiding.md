# 13. 사진 숨기기

설계: `../PHOTO_HIDING.md`

| ID | 시나리오 | 기대 결과 | 상태 | 메모 |
|---|---|---|---|---|
| HID-01 | v9 설치 위에 업데이트 | 크래시 없음, `hidden_media` 표 생성(user_version=10) | ⬜ | |
| HID-02 | 갤러리에서 사진 선택 → 숨기기 | 목록에서 사라지고 "N개를 숨겼습니다" | ⬜ | 동의 창이 뜨면 안 된다(파일을 안 건드리므로) |
| HID-03 | ⋮ → 숨긴 사진 보기 (최초) | 비밀번호 **설정** 화면. 안내 문구 표시 | ⬜ | |
| HID-04 | 4자리 미만 / 숫자 아닌 입력 | 확인 버튼 비활성 또는 형식 오류 | ⬜ | |
| HID-05 | 두 번 입력이 다를 때 | "두 번 입력한 비밀번호가 다릅니다" | ⬜ | |
| HID-06 | PIN 설정 완료 | 곧바로 숨긴 사진 목록 진입, 숨긴 사진이 보임 | ⬜ | |
| HID-07 | 뒤로 나갔다 다시 들어가기 | 다시 비밀번호를 묻는다 | ⬜ | 안 물으면 숨김이 아니다 |
| HID-08 | 틀린 PIN 5회 | 5회까지는 그냥 오류 문구 | ⬜ | |
| HID-09 | 6회째 실패 | "30초 뒤에 다시 시도할 수 있습니다", 카운트다운, 버튼 비활성 | ⬜ | |
| HID-10 | 잠긴 상태에서 앱 강제 종료 후 재진입 | 잠금이 유지된다 | ⬜ | 잠금 시각이 저장돼야 |
| HID-11 | 잠금 해제 후 맞는 PIN | 들어가지고 실패 횟수가 0으로 | ⬜ | |
| HID-12 | 숨긴 사진 선택 → 숨김 해제 | 목록에서 빠지고 갤러리에 다시 나타남 | ⬜ | |
| HID-13 | 숨긴 사진이 갤러리 **모든 탭**에 안 보이는지 | 전체·카메라·스크린샷·다른 앱 어디에도 없음 | ⬜ | 숨김이 탭보다 바깥 |
| HID-14 | 기간 선택 달력의 점·개수 | 숨긴 사진이 있던 날의 개수가 줄어듦 | ⬜ | 점이 있는데 목록이 비면 안 된다 |
| HID-15 | 상세보기 좌우 스와이프 | 숨긴 사진이 나오지 않음 | ⬜ | |
| HID-16 | 상세보기 ⋮ → 숨기기 | 목록에서 빠지고 이전 사진으로 이동 | ⬜ | 삭제와 같은 경로 |
| HID-17 | 숨긴 사진을 다른 앱에서 영구 삭제 후 재진입 | 목록에 유령이 남지 않음(`prune`) | ⬜ | |
| HID-18 | 앨범(이동 대상) 목록 | 숨긴 사진만 있는 폴더가 뜨지 않음 | ⬜ | 있다는 사실이 새면 안 된다 |
| HID-19 | 숨긴 사진 화면의 안내 문구 | "이 앱에서만 숨겨집니다…" 가 보임 | ⬜ | 과대 약속 방지 |
| HID-20 | 릴리스(R8) 빌드 | 동작 동일, 난독화로 깨지지 않음 | ⬜ | |
