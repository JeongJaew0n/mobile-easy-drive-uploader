# 03 · 갤러리 편집 (MediaStore CRUD)

모든 편집은 시스템 동의 다이얼로그를 거친다(Android 11+). 확인용으로는 **스크린샷 한 장을 즐겨찾기 → 해제** 하는 것이 가장 안전하다.

| ID | 시나리오 | 기대 결과 | 상태 | 메모 |
|---|---|---|---|---|
| CRUD-01 | 선택 → 하단 바 즐겨찾기 | 시스템 동의 → 별 배지 + 스낵바 "n개 항목을 즐겨찾기에 추가" | ⬜ | 동의 다이얼로그가 뜨는 것까지는 2026-09-08 확인 |
| CRUD-02 | 동의 다이얼로그에서 취소 | "취소했습니다", 변화 없음, 버튼 다시 활성 | ⬜ | |
| CRUD-03 | 전부 즐겨찾기인 선택에서 버튼 | 해제 동작(아이콘이 채워진 별 → 빈 별) | ⬜ | |
| CRUD-04 | 휴지통으로 이동 | 목록에서 사라짐(animateItem), ⋮ → 휴지통에 보임 | ⬜ | **비소유 파일이 휴지통 목록에 보이는지가 핵심 확인 포인트** — 안 보이면 MANAGE_MEDIA 필요 |
| CRUD-05 | 휴지통에서 복원 | 원래 날짜 위치로 복귀 | ⬜ | |
| CRUD-06 | 휴지통에서 완전 삭제 / 비우기 | 동의 후 제거, "30일 후 자동 삭제" 안내 | ⬜ | |
| CRUD-07 | 완전 삭제(하단 바) | 동의 → 즉시 제거 | ⬜ | |
| CRUD-08 | 이름 변경(단일 선택) — 확장자 생략 | `새이름.jpg` 로 저장(원본 확장자 유지), 힌트 문구 | ⬜ | 2단계 동의: 쓰기 동의 → update |
| CRUD-09 | 이름 변경 — 다른 확장자 입력 | 입력한 대로 저장 | ⬜ | |
| CRUD-10 | 앨범 이동 — 기존 앨범 선택 | 해당 `RELATIVE_PATH` 로 이동, 섹션 재정렬 | ⬜ | |
| CRUD-11 | 앨범 이동 — 새 앨범 이름 | `Pictures/<이름>/` 생성·이동, 영상도 동일 | ⬜ | |
| CRUD-12 | 이름 변경·이동 대상이 여러 개 | 이름 변경 버튼은 단일 선택에서만 활성 | ⬜ | |
| CRUD-13 | 설정 → "확인 없이 편집" → 시스템 설정에서 허용 | 돌아오면 "허용됨" 문구, 이후 편집 시 다이얼로그 없이 즉시 실행 | ⬜ | Android 12+ MANAGE_MEDIA |
| CRUD-14 | 편집 진행 중(다이얼로그 표시) 하단 바 | 버튼 비활성(isMutating) | ⬜ | |
| CRUD-15 | 상세보기에서 즐겨찾기·휴지통·이름 변경·이동·삭제 | 갤러리와 동일 흐름, 완료 후 같은 자리 다음 항목 | ⬜ | |
| CRUD-16 | API 29 기기 (`RecoverableSecurityException` 경로) | 동의 후 자동 재시도로 삭제·수정 완료, 휴지통·즐겨찾기 메뉴 숨김 | ➖ | 테스트 기기 없음 |
