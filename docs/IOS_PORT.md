# iOS 버전 — 얼마나 걸리나

2026-09-27 검토. **구현하지 않았다.** 무엇을 새로 짜야 하는지, 무엇이 iOS 에서 아예 안 되는지, 대략 몇 주인지 적는다.
일정은 추정이다 — 아래 "전제" 가 틀리면 같이 틀린다.

## 결론

- **iOS 앱을 하나 더 만드는 일이다.** 지금 코드는 거의 그대로 못 쓴다. 갤러리·백그라운드·로그인·화면이 전부 Android 전용이다.
- **최소 기능판(MVP) 3~4주, 지금과 거의 같은 기능 7~11주**(1인 + Claude, 지금과 같은 작업 방식 기준).
- **iOS 에서 제대로 안 되는 게 하나 있고, 그게 이 앱의 핵심이다 — 대량 백그라운드 업로드.** iOS 는 앱이 계속 돌며 수천 장을
  올리게 두지 않는다. "화면 끄고 두면 밤새 올라간다" 는 Android 만큼 보장되지 않는다(아래 §3.1).
- 시작하려면 **아이폰 실기기**와 **Apple Developer Program**(연 $99)이 먼저 있어야 한다. 지금은 둘 다 없다.

### Kotlin Multiplatform(KMP)으로 로직을 나눠 쓰면?

Drive 호출·큐·원장을 KMP 공용 모듈로 빼면 iOS 와 나눠 쓸 수 있다. 하지만 **지금은 권하지 않는다.**

- 공용으로 뺄 수 있는 순수 로직은 몇천 줄 수준이다. 나머지(갤러리·백그라운드·로그인·화면)는 어차피 둘 다 따로 짠다.
- 빼려면 Android 쪽을 먼저 바꿔야 한다. Retrofit → Ktor, Hilt → Koin 같은 교체가 필요하고, 이는 지금 `CLAUDE.md` 규칙
  ("Drive API 는 Retrofit") 과도 부딪힌다. 잘 돌아가는 앱을 흔드는 비용이 크다.
- **판단 시점:** iOS 판이 살아남아 두 앱의 같은 버그를 두 번 고치는 일이 실제로 쌓이면 그때 KMP 를 다시 본다.

**권하는 방식: SwiftUI 네이티브로 새로 짜고, `docs/` 의 설계를 그대로 따른다.**

### 3.1 백그라운드 업로드 — 가장 큰 차이

Android 는 포그라운드 서비스로 "업로드 중" 알림을 띄우면 앱이 계속 돈다. iOS 에는 이런 게 없다.

- **백그라운드 `URLSession`** 은 앱이 멈춰도 **이미 넘긴 전송**을 시스템이 이어서 한다. 대신 파일에서 올리는 것만 되므로,
  사진을 먼저 임시 파일로 꺼내 둬야 한다(대용량 영상이면 기기 공간을 잠깐 두 배로 쓴다).
- 다음 파일을 큐에서 꺼내 넘기는 일은 앱이 깨어 있을 때만 된다. 시스템이 언제 얼마나 깨워 줄지는 **보장이 없다.**
- `BGProcessingTask` 는 보통 **충전 중·유휴 상태**일 때 몇 분씩 돌려 준다. 밤새 충전하며 올리는 용도로는 쓸 만하다.
- 결과: 몇 장은 문제없다. **수천 장이면 "앱을 켜 두거나 충전기에 꽂아 둘 때 올라간다" 가 현실적인 약속이다.**

**이건 첫 주에 시제품으로 확인해야 한다.** 결과에 따라 iOS 판의 성격(백업 앱이냐, 올리기 도우미냐)이 바뀐다.

## 4. 일정

기준은 지금과 같은 작업 방식(1인 + Claude)이다. Android 판을 3주에 만들었지만 iOS 는 그보다 느리다고 본다.
설계를 이미 알고 있다는 이점보다, 실기기 확인이 불편하고(adb 같은 자동 조작이 약하다) 백그라운드 제약을 돌아가야 하는
비용이 크다.

| 단계 | 내용 | 기간 |
|---|---|---|
| 0. 준비·시제품 | 개발자 계정, iOS OAuth 클라이언트, Xcode 프로젝트. **백그라운드 업로드·다른 계정 로그인 시제품** | 3~5일 |
| 1. MVP | 갤러리 보기·뷰어, Google 로그인, 큐·원장, 업로드(앞에서 + 가능한 만큼 뒤에서), Drive 탐색 | 2~3주 |
| 2. 기본 기능 채우기 | Drive CRUD·격자, 다른 계정 업로드, 올린 사진 삭제, 숨김·카테고리·중복 | 2~3주 |
| 3. 나머지 | 원격 저장소 4종, 영상 압축, 자동 태그, 자동 백업 | 2~3주 |
| 4. 출시 | TestFlight, 개인정보 매니페스트·사진 권한 문구, App Store 심사(보통 1~3일, 반려되면 반복) | 약 1주 |
| **합계** | MVP 까지 **약 3~4주**, 거의 같은 기능까지 **약 7~11주** | |

### 줄이는 방법

- **3단계를 통째로 빼면 5~7주.** 원격 저장소·자동 태그는 쓰는 사람이 적다.
- **TestFlight 로만 쓰고 App Store 에 내지 않으면** 심사·문구 비용이 준다(TestFlight 빌드는 90일마다 다시 올린다).
- **iOS 에선 "Drive 로 올리기" 하나만 하는 앱**으로 좁히면 2~3주. 갤러리 관리는 iOS 사진 앱에 맡긴다.
